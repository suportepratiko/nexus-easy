# Som ao abrir operação

Coloque aqui o arquivo de áudio que será reproduzido quando o robô **abrir uma nova operação**.

- **Nome do arquivo:** `sucesso.mp3`
- Ex.: copie seu arquivo (ex.: `Sucesso 7.mp3`) para esta pasta e renomeie para `sucesso.mp3`.

O som pode ser ativado/desativado pelo ícone de volume no header da plataforma.
